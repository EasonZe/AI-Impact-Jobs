# 中国就业市场 AI 影响分析可视化网页

这是一个基于 HTML、CSS 和 JavaScript 制作的中国就业市场 AI 影响分析可视化网页项目。主要用于展示不同行业、不同职业在人工智能发展背景下可能受到的影响程度。

## 项目简介

本网页围绕“中国就业市场与 AI 影响”这一主题，模拟整理了中国常见职业数据，并结合 AI 对职业任务的自动化潜力、工具替代程度、行业采纳速度、物理技能需求、社交沟通需求等因素，对不同职业进行 AI 影响评分。

网页通过可视化方式展示职业分布和 AI 影响程度，帮助用户更直观地了解人工智能可能对不同职业、行业和就业结构带来的变化。

## 主要功能

- 中国职业数据展示
- AI 影响评分分析
- 职业树状图 Treemap 可视化
- 按就业人数展示职业面积大小
- 按 AI 影响程度展示颜色变化
- 职业详情查看
- 职业数据总览表
- 搜索职业功能
- 深色模式切换
- 适配电脑端和移动端浏览

## 数据说明

本项目中的职业数据、就业人数、收入水平、学历要求、就业前景和 AI 影响评分等内容为 AI 统计的分析数据。

## 技术栈

- HTML
- CSS
- JavaScript
- Treemap 可视化
- 响应式网页设计

## 项目特点

本项目尝试将职业数据、就业结构和 AI 影响评分结合起来，通过直观的图表形式展示人工智能对中国就业市场的潜在影响。相比传统表格展示，树状图可以更清楚地表现职业规模与 AI 影响程度之间的关系。
